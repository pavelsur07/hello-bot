# Доставка учебного магазина «Листва»

## Стоимость доставки

Для заказов учебного магазина «Листва» доставка по городу стоит 300 ₽.
При сумме заказа от 3 000 ₽ доставка по городу бесплатная.

## Сроки доставки

Доставка по городу занимает 1–2 рабочих дня после подтверждения заказа.
