# Демо-сценарии

Все названия, цены и условия в `examples/knowledge/` вымышлены. Запускайте
демо с явным путём `--knowledge-dir examples/knowledge`; рабочий каталог
`knowledge/` не должен автоматически включать эти документы.

| Сообщение клиента | Ожидаемое поведение |
| --- | --- |
| `Какая стоимость доставки по городу?` | Ответ: 300 ₽, бесплатно от 3 000 ₽; ссылка `examples/knowledge/delivery.md::Стоимость доставки`. |
| `Сколько стоит набор открыток?` | Ответ: 450 ₽; ссылка `examples/knowledge/pricing.md::Цена набора открыток`. |
| `Какие бонусы будут в программе?` | Нет подтверждённого ответа; черновик не используется. |
| `Вы ремонтируете велосипеды?` | Нет подходящего знания; бот сообщает об этом без выдуманного ответа. |
| `Какая стоимость ремонта велосипеда?` | Нет подходящего знания: совпадение по одному слову «стоимость» недостаточно. |
