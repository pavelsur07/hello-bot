# Тесты

После установки среды из README: python -m unittest discover -s tests -v.
Полная проверка: python scripts/check.py.

Тесты проверяют поиск, источники, отсутствие данных, черновики, повторы,
ошибки API, неизвестную отправку и pending после рестарта. Транспорт подменяется
opener; SQLite создаётся во временном каталоге. test_architecture.py проверяет
разрешённые импорты.

fixtures/telegram_updates.json содержит вымышленные события.
fixtures/classification_cases.json — набор для будущей оценки Jev, включая
неопределённые сообщения; это ещё не проверка настоящей классификации.
test_intent_decision.py проверяет диапазон confidence и сохранение низкой оценки.
Маршрутизация при низкой уверенности не реализована и не объявляется проверенной.

Не сохраняйте реальные сообщения, ключи или персональные данные.
Демо-статьи — в examples/knowledge/; тесты не подключают knowledge/
и не обращаются к сети.
