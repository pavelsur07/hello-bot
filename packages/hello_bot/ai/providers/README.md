# Провайдеры ИИ

Здесь будут реализации контрактов из `hello_bot.ai.contracts`:

- `jev.py`: структурированное решение для маршрутизации;
- `openai.py`: генерация текста;
- `kimi.py`: генерация текста.

Конфигурация выбирает провайдера по задаче. Наличие ключа не должно
автоматически включать модель без проверки качества на примерах обращений.
