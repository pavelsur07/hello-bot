# База знаний

Полные обязательные правила оформления находятся в корневом
[`KNOWLEDGE_RULES.md`](../KNOWLEDGE_RULES.md).

Этот каталог — источник знаний. Один Markdown-файл описывает одну тему.
Название файла должно быть стабильным и понятным. Разделы оформляйте
заголовками `##`: они станут единицами поиска и ссылками на источник.

Рекомендуемые метаданные в начале файла:

```yaml
---
id: delivery
title: Доставка
area: support
status: published
---
```

`area`: `sales`, `support` или `general`. В ответы попадают только
документы со статусом `published`. Меняйте `id` только при создании новой темы.
